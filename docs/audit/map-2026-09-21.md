## 4. 이 지도가 확인 못 한 것

- **커버리지는 실행이지 단언이 아니다.** 93~97%인 로직 층의 어느 줄이 재지 않은 채
  지나간 줄인지는 돌연변이만 답한다.
- Vue 파일의 템플릿(렌더 함수)이 v8 줄 수에 어떻게 세어지는지 **안 확인했다.** 화면
  층의 비율은 `<script setup>` 기준으로 읽어라.
- §2.1의 "없다"와 §2.3의 "안 나옴"은 **표기**(`grep`)다. 실물로 바꾸는 것이 R36·R37이다.
- 백엔드 관문(`uv run python scripts/ci.py`)은 안 돌렸다 — 범위 밖이다.
