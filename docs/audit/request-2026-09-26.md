## 산출 위치 (위의 스크래치패드 경로보다 우선한다)
하위 에이전트는 worktree 밖에 파일을 쓸 수 없다. **보고서·패치·설명은 전부 worktree 루트의 `_out/` 디렉터리에 쓴다** (예: `_out/report-R39b.md`, `_out/<묶음명>.patch`). 패치를 뽑을 때는 `_out`을 빼라: `git diff --binary HEAD -- . ":(exclude)_out" > _out/<묶음명>.patch`. 마지막 답장에 `_out` 파일들의 **절대 경로**를 적어라. 코드 소유자가 거기서 읽는다.

## 산출 위치 — 최종 (위의 모든 산출 경로보다 우선한다, 2026-09-26 확인)
