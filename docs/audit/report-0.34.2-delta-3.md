## A
- **A-3 폴백 미리보기와 확정이 값이 든 행이 적은 시트에서 아직 범위 전체를 훑는다** — `xlsx.ts:246-279`의 창 넓히기는 값이 든 행이 `maxRows`보다
  적으면 범위 끝까지 넓어진다(비용 = 범위 행 × 값이 든 폭). A1..A5 + XFD{N}(7KB): 미리보기 N=1,000 10.6s, N=2,000 36.9s(옛 49.3s). 확정도 폭이 상한
  안이면 같다 — A1..A5 + ALL{N}: N=20,000 확정 30.5s. 0.34.1부터 있던 병. 처방(실측): 값이 든 행만 모아 이어진 묶음마다 `sheet_to_json` → 122ms·5ms,
  8,800건 퍼즈 동치. **이웃 — 본진:** ExcelJS도 넘치지 않을 때는 빈 행마다 폭만큼 칸을 세운다(XFD N=2,000 미리보기 1.06s → 처방 9ms).

## 새로 연 것 (요청서 2)
상한 안의 정상 시트(병합·범위가 A가 아닌 시트·오류 칸·날짜·불리언·공백 칸·빈 행이 많은 시트·머리글 없는 끝 열·넓거나 좁은 dimension)는 옛 폴백과 같다.
창은 `maxRows`를 남긴 행으로 센다. `valueRows`의 행 수는 행 상한 판정과 같은 답을 낸다(본진·폴백 같음). 공통 축 — deflate·워커 없음, 실험 기록 지우는 새
길 없음, 제곱 이상 없음.
