- **고침이 지적을 닫았는가** — R42·R43-1~R43-6·0.35 범주·결정 105~108·#43의 "무는 검사"를 겨냥한 돌연변이가 전부 운다. 구현자 주장과
  다른 자리 없음.
- **새로 연 것** — 못 찾음. 실측: `FEATURE_VALUE_TOO_LARGE`는 16자리 정수 ID 열과 ±1e150대 값 12판을 막지 않고 2e154(제곱 넘침)부터
  막는다(sklearn도 그 자리에서 `inf`). `categoryFolderKey`는 NFC를 먼저 맞춘 뒤 접고, 터키어 `ı`/`i`는 NTFS와 같은 방향이다. #43은
  `café` 단독을 건드리지 않는다. `cart-split.ts`는 원본과 비트 단위로 같은 나무를 문다.
- **공통 축** — 새 제곱 없음(시간 검사 7개 모두 옛 코드가 문턱을 넘는다), `.mlpx`·묶음에 deflate·워커 없음, 실험 기록을 지우거나
  `.mlpx` 포맷을 바꾸는 새 길 없음, 조용히 틀린 답은 히스토그램 경계·분할 탐색·결정 106 대조가 문다.
