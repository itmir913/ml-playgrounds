## 0. 네가 §0에 적은 둘 — **반박한다. 둘 다 운다**

| 돌연변이 | 네가 적은 것 | 내가 잰 것 |

**그러니 *"`columns.ts`의 규칙이 아무 검사에도 안 걸려 있다"*는 결론은 틀렸다.**
걸려 있다.

### 내가 인정할 것 둘

**하나 — 보고서 머리글이 이르게 적혀 있었다.** *"작업 트리는 시작할 때 깨끗했고 끝날

## 1. A-1 — **두 쪽 다 맞다. 그런데 처방 2에 그물이 0이고, 남은 결함이 하나 있다**

### 1.1 네 고침은 내 하니스에서 깨끗하다

| | 되살아남 | 자물쇠 | 첫 고침에서는 |
|---|---|---|---|
| 갑(잠그기 전에 떠남) | **없음** | **안 쥠** (`released`가 trace에 있다) | 쥔 채였다 |
| 을(잠근 직후에 떠남) | **없음** | **안 쥠** | 안 쥠 |
| 병(그 뒤 재진입) | — | **새로 묻고 쥔다** (`request·granted`) | 안 묻었다 |
| 정(라우터 두 클릭) | **없음** | **안 쥠** | 쥔 채였다 |

그리고 A-1′로 지적한 자리 — `{쥔채: true, 다시열림: false}` — 가 **`{false, true}`로
돌아왔다.** `withTabLock` 이웃과 BroadcastChannel 폴백도 같이 초록이다.

### 1.2 의심 넷에 답한다

**의심 1 — `projectId`로 재는 것과 번호로 재는 것이 다른가. 네가 맞다.** 여는 중에
`file.value`는 아직 `null`이라 *"닫혔다"*와 *"아직 안 열렸다"*가 같은 모양이다. 번호가
아니면 못 가른다. 반박할 것이 없다.

**의심 2 — 토스트. 안 뜬다. 그리고 대조도 맞다.** 잰 값:

| | `open()` | 토스트 수 | 열린 프로젝트 | 자물쇠 |
|---|---|---|---|---|
| 취소당함(`close()`가 잡는 중에) | `false` | **0** | `null` | 안 쥠 |
| 남이 쥠(대조) | `false` | **1** | — | — |

**의심 3 — 겹친 취소. 둘 다 낡는다.** 열기 둘을 겹쳐 띄우고 `close()`를 한 번 보냈더니
`results: [false, false]` · `open: null` · `lock: false`다. **번호라서 서로의 신호를 안
지운다** — `boolean`이었으면 갈렸을 자리다.

**의심 4 — `withTabLock`의 `finally`.** 내 스펙(`지운 프로젝트의 자물쇠가 안 남는다`)이
**초록**이고, 네 검사에 돌연변이를 심으면 그 줄도 함께 운다(V3). 이웃까지 닫혔다.

### 1.3 **처방 2에는 그물이 0이다** — 여기가 이번 회신의 핵심이다

`stores/project.ts`의 세 줄을 각각 지우고 **전체 스위트**를 돌렸다.

| 지운 것 | 결함이 돌아오는가 | 전체 스위트 |
|---|---|---|
| `if (stale()) return false` (되살림 가드) | **돌아온다** | **전부 초록 (3,838개)** |
| `if (!stale())` (토스트 가르기) | **돌아온다** | **전부 초록** |
| `if (stale()) { releaseTabLock(); … }` | **돌아온다** | **전부 초록** |

**좁은 목록으로 먼저 재고(`r37-tab-lock`·`project-open-lock`·`router`·`autosave`·
`welcome-fail`) 그 다음에 전체로 다시 쟀다** — `report-R37.md` §3.2에서 좁은 목록이 둘을
거짓으로 조용하게 만든 적이 있어서다. 이번에는 양쪽 다 조용하다.

**즉 A-1의 tab-lock 쪽은 `r37-tab-lock.spec.ts`가 단단히 물지만, 스토어 쪽은 코드만 들어가
있고 지키는 것이 없다.** 다음에 누가 `open()`을 손대면 조용히 되돌아간다 — 이 저장소가
*"규칙을 세우면 그 자리에서 검사를 세운다"*로 적어 둔 자리다.

**세울 수 있다.** 내가 쓴 하니스가 그대로 그 검사다 — 가짜 Web Locks의 **허가 시점을
손에 쥐고** 그 사이에 `close()`를 넣으면 결정적이다. 그 셋을 스크래치패드에 남겼다:
`zz-r37-router.spec.ts`(갑·을·병·정) · `zz-r37-verify.spec.ts`(토스트·겹친 취소) ·
`zz-r37-lock.spec.ts`(잠금만). **가져다 쓰라고 남긴 것이지 내가 심을 것은 아니다.**

### 1.4 남은 결함 하나 — **학생이 [점검]을 눌렀는데 목록에 선다**

**자리** `router/index.ts:137`

```ts
if (!(await project.open(projectId))) {
  return { name: ROUTE_PROJECTS }   // ← 취소당한 경우에도 리다이렉트한다
}
```

`open()`은 *"취소당함"*과 *"남이 쥠"*을 **안에서는 가른다**(그것이 토스트 고침이다).
그런데 밖으로는 `boolean` 하나라 **가드가 그 둘을 못 가른다.** 취소는 학생이 이미
다른 데로 가고 있다는 뜻인데, 여기서 목록으로 리다이렉트하면 **그 이동을 덮어쓴다.**

잰 값(라우터를 실제로 태웠다):

```
학생이 누른 곳: inspect    선 곳: projects    목록인가: true
```

**고침 전보다 나빠진 것은 아니다** — 전에는 주소가 `inspect`였지만 프로젝트가 되살아나고
자물쇠가 샜다. 지금은 상태가 깨끗하고 **화면만 틀리다.** 그래서 A가 아니라 C다.

**처방.** 취소면 리다이렉트가 아니라 **중단**이 맞다(`return false`) — 새 이동이 이미
학생이 가려는 곳으로 가고 있다. 그러려면 `open()`이 세 갈래를 말해야 한다. 토스트를
가른 축이 이미 있으니 **그 축을 밖으로 한 칸 내보내는 것**이 전부다.

## 2. A-2 — **원시 연산은 맞다. 그런데 읽는 자리가 셋이 아니라 넷이다**

### 2.1 의심 1 — 서른 가지가 사라졌는가. **사라졌다**

다섯 이름(`constructor`·`toString`·`valueOf`·`hasOwnProperty`·`__proto__`) × 여섯 자리
(`isPortfolioAnswered`·`portfolioSections`·`attachmentsOf`·`photosOf`·
`withAttachmentAdded`·`renderPortfolioMarkdown`)를 **진짜 입구**(교사 양식을
`parsePortfolioForm`으로 파스)로 다시 돌렸다 — **서른 가지 전부 초록.**

네 검사(`r37-fixes.spec.ts`)도 단단하다: 읽는 자리 셋을 각각 되돌리면 **셋 다 운다**(V7·V8·V9).

### 2.2 의심 2 — 읽는 자리가 셋뿐인가. **아니다. 넷이다**

`grep`으로 다시 셌다. `answers[…]`·`attachments[…]`를 **평범한 객체로 색인하는 자리**가
하나 더 있다.

```ts
// views/PortfolioView.vue:194 — setAnswer의 되돌리기
element.value = portfolio.value.answers[id] ?? ''
```

**닿는 길이 있다.** `apply()`의 `revert`는 `portfolioBytes(next, …) > limit`일 때 돈다 —
**`PORTFOLIO_TOO_LARGE`**. 그러니 교사 양식에 `{#constructor}` 문항이 있고 학생이 **그
문항에 처음** 상한을 넘는 글을 붙여넣으면, 되돌리기가 칸에 **`function Object() { [native
code] }`** 를 적는다. 그 뒤 그 칸의 글자가 곧 답이 된다.

**좁다. 그래도 같은 뿌리이고 고침이 안 닿았다.** 원인이 분명하다 — **`own()`이 모듈
밖으로 안 나간다**(`function own`, `export` 없음). 원시 연산을 세웠는데 **네 번째 소비자가
그것을 부를 길이 없어서** 옛 표기로 남았다. 「흩어진 결함은 빠진 연산이다」가 말하는
모양 그대로다.

**처방은 그 파일 안에 이미 있다.** 바로 **여덟 줄 아래**의 `setTitle`이 같은 일을
색인 없이 한다.

```ts
function setTitle(id: string, text: string, element: HTMLInputElement): void {
  apply(withSectionText(portfolio.value, id, { title: text }), () => {
    element.value = sections.value.find((section) => section.id === id)?.title ?? ''
  })
}
```

`sections`는 `portfolioSections()`가 만든 것이라 **이미 `own()`을 지난 값**이다.
`setAnswer`도 같은 모양으로 쓰면 된다 — `…?.answer ?? ''`. **형제 둘 중 하나만 옛
표기로 남은 것**이라, 고치는 쪽이 새 개념을 안 들여도 된다.

(`own`을 내보내는 길도 있지만 그건 화면에 색인을 계속 허락하는 것이다. 굳이 내보낸다면
이름은 `answerOf(portfolio, id)`처럼 **뜻이 있는 것**이어야 다음 소비자도 같은 문을 지난다.)

### 2.3 의심 3 — `withAnswer`가 own 속성을 만든다는 성질에 기대고 있는가. **아니다**

계산된 열쇠(`{ ...answers, [id]: answer }`)는 `__proto__`라도 own 속성을 만든다. 다만
**읽는 쪽이 고쳐졌으므로 그 성질에 안 기댄다** — 답이 없는 상태에서도 전부 초록이다
(위 서른 가지가 그 상태에서 잰 것이다).

**C-5는 그대로다** — `ml/engines/mljs.ts:250`·`pyodide-sklearn.ts:345`의
`PARAMETERS[algorithm] ?? []`. 네 말대로 이번에도 안 고쳤고, **나도 재현 안 했다.**

## 3. A-3 — **네가 한 칸 더 옮긴 것이 맞다. 다만 합친 두 뜻에 그물이 없다**

### 3.1 옮긴 것 자체는 옳다 — 그리고 물린다

**`scatterOptions`가 되돌린 뒤 넘기는 설계에 반박할 것이 없다.** 내 원래 처방은 화면

### 3.2 의심 1 — 군집 화면 셋이 안 다쳤는가. **안 다쳤다. 그런데 그 초록이 증거가 아니다**

`cluster-chart.spec.ts`·`cluster-scatter.spec.ts`는 초록이다 — **깨진 것은 없다.**

**다만 그 초록으로는 아무것도 증명이 안 된다.** V11(`Math.round` → `Math.trunc`)을 심었을
때 **운 것은 `r37-fixes.spec.ts` 하나뿐이고 군집 스펙 둘은 조용했다.** 즉 군집 화면의
좌표 글자는 **고침 전에도 후에도 무검사**다 — `cluster-chart.spec.ts`가 보는 것은
`tooltip.filter`와 `.position`이지 `label` 콜백이 아니다(`chart-config.spec.ts`가
`point: () => ''` 스텁을 넘기는 것과 같은 모양이다).

**그래서 이 이사는 군집 쪽에 그물을 더해 주지 않았다.** 데이터 화면 쪽만 새로 물린다.
군집 쪽도 닫으려면 `clusterChartOptions`가 만든 `label` 콜백을 직접 부르면 된다 —
`r37-fixes.spec.ts`가 데이터 화면에 한 것과 같은 한 줄이다.

### 3.3 의심 2 — `unknownCategory`가 두 뜻을 갖게 된 것. **네 판단을 반박하지 않는다. 다만 그물이 0이다**

**합친 것 자체는 지금 맞다.** 화면 둘 다 그 자리에 `없음`을 적고, *"범주 번호에 이름이
없다"*와 *"값이 없다"*는 학생에게 같은 사실이다 — 둘 다 **이 점에 대해 할 말이 없다**는
뜻이다. 뜻을 굳이 가르면 화면이 둘을 다르게 말해야 하는데, 그 문장이 무엇인지 지금
아무도 모른다. 안 가르는 쪽이 맞다.

**문제는 그 `null` 갈래를 아무것도 안 잰다는 것이다.** `value === null`을
`{ kind: 'number', value: 0 }`으로 바꿔도 **전체 스위트가 조용하다**.

**즉 뜻이 갈리는 날이 아니라 지금 이미 무검사다.** 한 줄이면 닫힌다.

### 3.4 의심 3 — 브라우저. **나도 안 봤다**

동의한다. 이 고침의 최종 확인은 코드 소유자의 눈이고, `report-R37.md` §4의 *"못 한 것"*에
그대로 남아 있다.
