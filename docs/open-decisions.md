# 열려 있는 결정

**구현 전 반드시 확인한다.** 잘 모르겠으면 추측해서 구현하지 말고 여기 항목을 추가하고 물어라.

- 결정문마다 **상태 한 줄**(`**[미정]**`·`**[결정]**`·`**[폐기]**`)과, 제목이 물음일 때만 **결론 한 줄**을 둔다.
  무엇을 재고 무엇을 기각했는지는 같은 제목 아래 `docs/cases/open-decisions.md`에 있다 (`docs/workflow.md` §8).
- **미결정**(이 파일)은 처음부터 끝까지 읽는다. **결정이 닫혀도 구현이 남았으면 여기 둔다.**
- **결정됨**(`open-decisions/` 아래)은 통독하지 않는다. 다른 문서나 코드가 제목으로 가리킬 때 그 항목만 편다.
  아래 색인이 제목이 어느 파일에 있는지 말한다.
- **제목은 주소다. 한 번 적은 제목을 바꾸지 마라.** 미결정에서 결정됨으로 옮길 때도 제목은 그대로 옮긴다.
