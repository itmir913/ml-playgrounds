# 이 저장소가 무엇인가

> **규칙이 아니라 소개다.** 규칙은 `CLAUDE.md`와 그것이 가리키는 문서에 있다.

**ML Playgrounds** — 중·고등학교 정보/인공지능 수업에서 학생이 데이터를 올려 모델을
만들고, 분석하고, 포트폴리오를 써서 **하나의 프로젝트 파일**로 제출하는 교육용 플랫폼.

- **누구를 위한가** — 중·고등학교 정보/인공지능 수업의 교사와 학생.
- **어디서 쓰는가** — 전국 단위. 학교 PC, 가정 PC, 휴대폰.
- **무엇이 다른가** — Orange3(워크플로 편집기)와 Teachable Machine(즉석 모델 생성)이 놓치는
  "학생이 프로젝트를 만들고 그 과정을 남기는 경험"을 준다.
- **흐름** — 새 프로젝트 → 데이터 → 전처리 → 학습 → 결과 분석 → 예측 → 포트폴리오 → `.mlpx` 저장.
- **스택** — 프런트엔드 Vue 3 (`<script setup>`) · TypeScript strict · Tailwind · Pinia · vue-i18n · IndexedDB · Vite,
  백엔드 Python 3.12+ · FastAPI · Pydantic v2 · scikit-learn / pandas / numpy. 요구 버전과 실행 명령은 `README.md`.
- **배포** — GitHub Pages 정적 배포(공식)와 도커 자가호스팅(선택).
- **저장소** — `https://github.com/itmir913/ml-playgrounds` · 라이선스 MIT.
- **범위와 지금 어디인가** — `docs/roadmap.md`.
