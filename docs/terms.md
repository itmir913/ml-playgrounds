# 용어 사전

> 이 프로젝트에서 쓰는 용어의 뜻을 정한다.
> 담는 것은 **용어 · 영문 · 뜻**뿐이다. 화면 문구는 `ko.json`이 유일한 출처다.

**`훈련`과 `학습`이 갈리는 자리가 하나 있다** — 되풀이해서 흔들리는 곳이라 규칙으로 적어 둔다.

> **데이터의 이름은 `훈련`/`테스트`, 그 데이터로 하는 일은 `학습`이다.**

영어가 정확히 같은 갈래다 — machine **learning** · **learning** rate 인데 **training** data ·
`train_test_split`. **모델은 배우고, 데이터는 훈련용이다.** 그리고 `기계학습`·`지도학습`·
`학습률`은 바꿀 수 없는 말이라, 동작까지 `훈련`으로 밀면 `훈련된 기계학습 모델`처럼
어간이 부딪히고 **왜 갈리는지 설명할 규칙이 없어진다.**

---

## 기계학습 유형

### 기계학습 (Machine Learning)

컴퓨터가 데이터에서 패턴을 찾아 스스로 판단 규칙을 만드는 기술.

### 지도학습 (Supervised Learning)

정답이 붙은 데이터를 주고 학습시키는 방식. 분류와 회귀가 여기에 속한다.

### 비지도학습 (Unsupervised Learning)

정답 없이 데이터의 구조나 패턴을 찾는 방식. 군집화가 여기에 속한다.

### 분류 (Classification)

데이터를 정해진 범주 중 하나로 나누는 과제.

### 회귀 (Regression)

연속적인 수치를 예측하는 과제.

### 군집화 (Clustering)

비슷한 데이터를 그룹으로 묶는 과제. 정답 없이 데이터만으로 그룹을 찾는다.

---

## 알고리즘

### 의사결정트리 (Decision Tree)

질문을 나무 모양으로 이어가며 데이터를 분류하거나 값을 예측하는 알고리즘.

### 랜덤 포레스트 (Random Forest)

여러 의사결정트리를 만들어 다수결로 답을 정하는 앙상블 알고리즘.

### 로지스틱 회귀 (Logistic Regression)

데이터가 특정 범주에 속할 확률을 구해 분류하는 알고리즘.
이름에 회귀가 들어가지만 분류에 쓴다.

### K-최근접 이웃 (K-Nearest Neighbors)

새 데이터와 가장 가까운 k개의 데이터를 찾아 다수결로 분류하는 알고리즘.

### 나이브 베이즈 (Naive Bayes)

베이즈 정리를 바탕으로, 특성들이 서로 독립이라 가정하고 분류하는 알고리즘.

### 서포트 벡터 머신 (Support Vector Machine)

데이터를 가장 넓은 간격으로 나누는 경계를 찾아 분류하는 알고리즘.

### 선형 회귀 (Linear Regression)

입력과 출력 사이의 관계를 직선으로 표현해 연속적인 값을 예측하는 알고리즘.

### K-평균 (K-Means)

데이터를 k개의 군집으로 나누되, 각 군집의 중심점까지 거리가 최소가 되도록
반복하는 알고리즘.

---

## 데이터

### 데이터셋 (Dataset)

학습이나 평가에 사용하는 데이터 묶음.

### 특성 (Feature)

모델이 예측에 사용하는 입력 열.

### 타깃 (Target)

모델이 예측하려는 출력 열. 분류에서는 범주, 회귀에서는 수치다.

### 레이블 (Label)

분류에서 데이터에 붙은 정답 범주. 타깃의 분류 전용 동의어.

### 범주 (Class)

분류에서 데이터가 속하는 그룹 하나하나.

### 수치형 · 범주형 (Numeric · Categorical)

열의 자료형. 숫자로 다룰 수 있으면 수치형, 이름이나 종류처럼 순서 없는 값이면
범주형.

---

## 전처리

### 전처리 (Preprocessing)

데이터를 모델에 넣을 수 있는 형태로 바꾸는 과정.

### 결측치 (Missing Value)

데이터에서 비어 있는 값.

### 이상치 (Outlier)

보통의 범위에서 크게 벗어난 값.

### 스케일링 (Scaling)

수치 열의 크기를 일정한 범위나 분포로 맞추는 전처리.

### 표준화 (Standardization)

평균을 빼고 표준편차로 나누어 평균 0, 분산 1로 만드는 스케일링.

### 정규화 (Normalization)

최솟값과 최댓값을 이용해 0에서 1 사이의 범위로 바꾸는 스케일링.
같은 단어가 규제(regularization)의 뜻으로도 쓰이므로 맥락에 주의한다.

### 로버스트 스케일링 (Robust Scaling)

중앙값과 사분위 범위를 이용해 이상치에 덜 민감하게 스케일링하는 방법.

### 원-핫 인코딩 (One-Hot Encoding)

범주형 값을 범주 수만큼의 0/1 열로 바꾸는 인코딩.

### 순서 인코딩 (Ordinal Encoding)

범주형 값을 0, 1, 2, … 순서 번호로 바꾸는 인코딩.

## 훈련과 평가

### 훈련 (Training)

데이터를 모델에 넣어 패턴을 익히게 하는 과정.

### 훈련 데이터 (Training Data)

모델을 훈련시키는 데 사용하는 데이터.

### 테스트 데이터 (Test Data)

훈련된 모델의 성능을 확인하는 데 사용하는 데이터.
훈련에는 쓰지 않는다.

### 훈련/테스트 분할 (Train-Test Split)

데이터를 훈련용과 테스트용으로 나누는 것.

### 홀드아웃 (Holdout)

데이터를 한 번만 훈련용과 테스트용으로 나누는 분할 방식.

### 교차 검증 (Cross-Validation)

데이터를 여러 번 나눠 훈련과 평가를 반복하고 성능을 종합하는 방식.

### 층화 분할 (Stratified Split)

분할할 때 각 범주의 비율을 훈련 데이터와 테스트 데이터에 똑같이 유지하는 방법.

### 난수 씨앗 (Random State)

무작위 과정의 시작점. 같은 값이면 같은 결과가 나온다.

### 모델 (Model)

데이터에서 배운 패턴을 담고 있는 것. 새 데이터가 들어오면 이것으로 예측한다.

### 예측 (Prediction)

훈련된 모델이 새 데이터에 대해 답을 내놓는 것.

### 실험 (Experiment)

같은 데이터와 전처리 아래 여러 모델을 돌려 비교하는 작업 단위.

---

## 평가 지표 — 분류

### 혼동 행렬 (Confusion Matrix)

분류 결과를 실제 값과 대비해 정리한 표.
행이 실제 범주, 열이 예측 범주다.

### 정확도 (Accuracy)

전체 데이터 중 모델이 올바르게 분류한 비율.

### 정밀도 (Precision)

모델이 어떤 범주라고 답한 것 중에서 실제로 그 범주였던 비율.

### 재현율 (Recall)

실제로 어떤 범주인 데이터 중에서 모델이 그 범주로 찾아낸 비율.

### 특이도 (Specificity)

실제로 어떤 범주가 아닌 데이터 중에서 모델이 아니라고 바르게 판단한 비율.

### F1 점수 (F1 Score)

정밀도와 재현율의 조화 평균. 둘 사이의 균형을 하나의 수치로 나타낸다.

### 지지 (Support)

테스트 데이터에서 해당 범주에 실제로 속하는 데이터 수.

---

## 평가 지표 — 회귀

### 결정계수 (R²)

모델이 데이터의 변동을 얼마나 설명하는지 나타내는 지표. 1에 가까울수록 좋다.

### 평균 제곱근 오차 (RMSE)

예측값과 실제값 차이의 제곱을 평균 낸 뒤 제곱근을 취한 값.
단위가 원래 데이터와 같아서 해석하기 쉽다.

### 평균 절대 오차 (MAE)

예측값과 실제값 차이의 절대값을 평균 낸 값.

### 평균 제곱 오차 (MSE)

예측값과 실제값 차이의 제곱을 평균 낸 값.

---

## 평가 지표 — 군집화

### 실루엣 계수 (Silhouette Coefficient)

군집화 결과에서 각 데이터가 자기 군집과 얼마나 잘 맞고 다른 군집과 얼마나
떨어져 있는지 나타내는 지표. −1에서 1 사이이고, 1에 가까울수록 좋다.

### 이너셔 (Inertia)

각 데이터와 자기 군집의 중심점까지 거리의 제곱합. K-평균의 목적함수다.
낮을수록 좋지만, 군집 수(k)를 올리면 무조건 내려가므로 단독으로 "좋다"를
말할 수 없다.

---

## 과적합과 일반화

### 과적합 (Overfitting)

모델이 훈련 데이터에 지나치게 맞춰져서 새 데이터에 대한 성능이 떨어지는 현상.

### 과소적합 (Underfitting)

모델이 데이터의 패턴을 충분히 익히지 못해 훈련 데이터에서도 성능이 낮은 현상.

---

## 하이퍼파라미터

### 하이퍼파라미터 (Hyperparameter)

훈련 전에 사람이 정해 주는 값. 모델이 스스로 배우는 것이 아니다.

### 최대 깊이 (Max Depth)

의사결정트리가 자랄 수 있는 최대 단계 수.

### 이웃 수 (n_neighbors)

K-최근접 이웃에서 참고하는 가장 가까운 데이터의 개수.

### 나무 개수 (n_estimators)

랜덤 포레스트에서 만드는 의사결정트리의 수.

### 최대 반복 횟수 (max_iter)

반복 알고리즘이 최대 몇 번 돌 수 있는지 정하는 값.

### 수렴 판정 기준 (Tolerance)

반복 중 변화가 이 값보다 작으면 훈련이 끝났다고 판단하는 기준.

### 규제 강도 (C)

서포트 벡터 머신과 로지스틱 회귀에서 오분류 허용 정도를 조절하는 값.
클수록 경계를 엄하게 지킨다.

### 군집 수 (n_clusters)

K-평균에서 데이터를 나눌 군집의 개수. sklearn의 파라미터 이름이 `n_clusters`다.

## 기타 개념

### 특성 중요도 (Feature Importance)

모델이 예측할 때 각 특성이 얼마나 영향을 미쳤는지 나타내는 값.

### 앙상블 (Ensemble)

여러 모델을 합쳐 하나보다 나은 성능을 얻는 방법.

### 마진 (Margin)

서포트 벡터 머신에서 결정 경계와 가장 가까운 데이터 사이의 간격.

### 서포트 벡터 (Support Vector)

서포트 벡터 머신에서 결정 경계에 가장 가까이 있는 데이터 점.

### 가지치기 (Pruning)

의사결정트리에서 불필요한 가지를 잘라 과적합을 줄이는 기법.

### 확률 (Probability)

분류 모델이 각 범주에 속할 가능성을 수치로 나타낸 것.

### 중심점 (Centroid)

K-평균 알고리즘에서 각 군집의 중심이 되는 점.

### 포트폴리오 (Portfolio)

프로젝트 과정과 결과를 글로 정리한 문서.

### 프로젝트 (Project)

데이터, 실험, 결과, 포트폴리오를 하나로 묶는 작업 단위.
