# 소스를 쓰고 되돌리는 법

### 2026-09-01 — 트립와이어를 `checkout --`로 되돌리다 작업이 날아갔다

- **무슨 일이 있었나.** 검사가 우는지 보려고 심은 결함을 `git checkout -- <파일>`로
  되돌렸는데, 같은 파일에 살아 있던 내 수정까지 함께 날아갔다. 한 번이 아니었다.
- **뿌리.** 되돌리는 단위가 "심은 것"이 아니라 "파일"이었다.
- **생긴 규칙.** `CLAUDE.md` §4 — 되돌리기는 심은 것만 되돌린다.
- **지키는 검사.** 없다(사람 확인).

### 2026-09-22 — 힙독 금지 규칙이 있는데도 또 밟았다

- **무슨 일이 있었나.** 셸 힙독으로 검사 파일을 쓰다 `\b`가 제어문자(0x08)가 되어
  파일이 파스조차 안 됐다. 규칙은 이미 `CLAUDE.md`에 있었다. 이전에도 `/\\/g`가
  `/\/g`가 되어 정규식이 아무것도 안 잡는 채로 초록불이 된 적이 여러 번 있었다.
- **뿌리.** 사람(모델)이 지키길 기대하는 규칙이었다.
- **생긴 규칙.** `CLAUDE.md` §4 — 힙독 금지를 규칙에서 훅으로 옮겼다.
- **지키는 검사.** `.claude/hooks/no-heredoc.mjs`.
