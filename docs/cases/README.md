# 판례

> **이것은 기록이지 규칙이 아니다.** 현재 규칙은 각 건이 가리키는 절에서 확인하라.
> 잘 쓰인 경위를 규칙으로 읽지 마라 — 그 뒤에 규칙이 바뀌었을 수 있다.

규칙과 판례를 나누는 이유와 형식은 `docs/workflow.md` §8이 갖는다.

- **주제마다 파일 하나에 누적한다.** 하위 디렉터리로 쪼개지 않는다.
- 한 건은 `### YYYY-MM-DD — 제목` 아래 무슨 일이 있었나 / 뿌리 / 생긴 규칙 / 지키는 검사.
- **추가만 하고 고치지 않는다.** 규칙이 바뀌면 새 건을 쓰고 옛 건을 가리킨다.
