# 판례

> **이것은 기록이지 규칙이 아니다.** 현재 규칙은 같은 이름의 규칙 문서에서 확인하라.
> 잘 쓰인 경위를 규칙으로 읽지 마라 — 그 뒤에 규칙이 바뀌었을 수 있다.

위계는 셋이다 (`docs/workflow.md` §8).

| 층 | 무엇을 담는가 |
|---|---|
| `CLAUDE.md` | 절대 규칙 한 줄과, 어떤 경우에 어느 문서를 볼지 |
| `docs/X.md` | 그 분야의 규칙만 |
| `docs/cases/X.md` | `docs/X.md` 규칙의 이유·결정 과정·판례 |

- **규칙 문서 하나에 판례 파일 하나, 이름이 같다.** 하위 디렉터리로 쪼개지 않는다.
- 절 번호와 제목은 규칙 문서를 따르고, 사고는 끝의 "판례"에 `### YYYY-MM-DD — 제목`으로 쌓는다.
  한 건은 무슨 일이 있었나 / 뿌리 / 생긴 규칙 / 지키는 검사.
- **추가만 하고 고치지 않는다.** 규칙이 바뀌면 새 건을 쓰고 옛 건을 가리킨다.
